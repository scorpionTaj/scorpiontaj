## 🚀 About Me

I'm a Data & AI Engineer with a Master's in Data Science and Artificial Intelligence from the Faculty of Sciences, Moulay Ismail University (Meknès, 2026).

I build ML and deep learning models together with the data pipelines and MLOps stack that run them in production. My final-year project at OCP S.A. was an end-to-end predictive-maintenance system for CAT D11T bulldozers. Before that, at XAI, I built a FastAPI gateway that routes requests across multiple LLM providers. On my own time I work on RAG for Moroccan Darija, self-healing ML pipelines and medical imaging.

I'm a former board member of the Moroccan Data Science Community, where we promoted data science knowledge and open data across Morocco.

When I'm not coding, I'm doing bodybuilding, swimming or travelling. I speak Arabic, English and French.

## 🚀 Featured Projects

| Project | What it does | Stack |
|---|---|---|
| [**Darija RAG**](https://github.com/scorpionTaj/darija-rag) | Local RAG over 8 official Moroccan legal texts that answers in Darija, Arabizi, MSA and French with page citations, and says so when the documents don't contain the answer. BGE-M3 retrieval, LLM query rewriting and cross-encoder reranking lift Recall@10 from 0.64 (BM25) to 0.93 on 264 questions. | Python, PyTorch, BGE-M3, Tesseract OCR, Docker |
| [**Sentinel MLOps**](https://github.com/scorpionTaj/Sentinel-MLOps) | Self-healing ML pipeline: PSI drift detection triggers retraining, offline validation, a canary release and then promotion or rollback. Its RUL model on NASA C-MAPSS reaches test RMSE 14.5, against 41.9 for the baseline. | Python, NumPy, FastAPI, Docker |
| [**MediScan**](https://github.com/scorpionTaj/MediScan) | Pneumonia detection from chest X-rays with EfficientNet-B0 trained on 15,000+ images (94.2% accuracy, 93.8% sensitivity), with Grad-CAM explanations and a Dockerized web app. | TensorFlow, Flask, Next.js, Docker |
| [**MCP Workbench**](https://github.com/scorpionTaj/mcp-workbench) | Platform that puts 12 LLM providers behind one streaming chat, with approval-gated MCP servers, pgvector knowledge bases and an in-browser Python notebook (Pyodide). | Next.js, React, TypeScript, Drizzle ORM, PostgreSQL/pgvector, Redis, Docker |
| [**Tourist Analytics**](https://github.com/scorpionTaj/tourist-analytics) | Big Data pipeline for Airbnb data from several cities: HDFS storage, Spark batch jobs, Cassandra and Neo4j serving layers, a FastAPI API and a Streamlit dashboard, run with Docker Compose. | Hadoop HDFS, Spark, Cassandra, Neo4j, FastAPI, Streamlit |
| [**Fake News Detection**](https://github.com/scorpionTaj/fake-news-detection-and-classification) | RoBERTa fine-tuned on FakeNewsNet (GossipCop & PolitiFact), with strict deduplication and a decision threshold tuned to maximize F1. | PyTorch, Hugging Face Transformers |
